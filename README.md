# BisBetania

Мобильное приложение для церкви Betania: Библия без интернета со стихом дня, планы чтения, молитвенный дневник, расписание служений, пожертвования через MIA/QR и история церкви на YouTube.

## Что нового в 1.1

- **Библия внутри приложения, без интернета** — Cornilescu 1924 (RO) и Синодальный перевод (RU), все 66 книг; выделение стихов цветом, копирование, «поделиться», размер и стиль шрифта, «продолжить чтение».
- **Стих дня на главном экране** — каждый день новый из ~190 самых известных стихов, на RO и RU (нумерация Псалмов сверена с Синодальным переводом).
- **Поиск по Библии** — без учёта регистра и румынских диакритик (`pastorul` находит «Păstorul»).
- **Планы чтения** — Евангелия за 30 дней, Псалмы и Притчи, Новый Завет за 90 дней, Библия за год; чтение на сегодня и отметка «прочитано» прямо на главной.
- **Молитвенный дневник** — личные просьбы, отметка «отвечено», отправка просьбы церкви через любой мессенджер.
- **Расписание служений и объявления** с отсчётом до ближайшего служения; **контакты и прямой эфир** (YouTube @BETANIAMOLDOVA).
- **Оформление** — 6 цветов приложения, светлая/тёмная/системная тема, классический шрифт для Библии.
- **Уведомление со стихом дня** в выбранное время (работает в установленном APK; в Expo Go Android уведомления отключены).
- Язык, тема, закладки, планы и молитвы сохраняются на телефоне.

## Как обновлять расписание без новой версии

Файл [`content/church.json`](content/church.json) приложение скачивает с GitHub при запуске (с копией для офлайна). Чтобы поменять расписание, объявления, адрес или телефон — отредактируйте этот файл прямо на GitHub в ветке `main`. `day`: 0 = воскресенье … 6 = суббота.

> Сейчас расписание и контакты в этом файле — **примеры**, их нужно заменить реальными.

## Пожертвования

- выбор фиксированной суммы пожертвования: `50`, `100`, `200`, `500 MDL`;
- ввод своей суммы вручную;
- генерация QR-кода под выбранную сумму;
- переход на MIA payment link через встроенный браузер;
- копирование выбранной суммы в буфер обмена;
- экран благодарности после пожертвования;
- переключение языка интерфейса `RU / RO`;
- раздел "История Церкви" с YouTube-видео;
- адаптированный мобильный дизайн под iOS/Android.

## Запуск проекта

Перед запуском нужен установленный Node.js и Expo development environment.

```bash
git clone https://github.com/cs1lyuha/bisbetania.git
cd bisbetania
npm install
npx expo start
```

После запуска Expo можно открыть приложение:

- через Expo Go, отсканировав QR-код в терминале;
- на Android-эмуляторе;
- на физическом Android-устройстве;
- через development build.

Для запуска Android build из проекта:

```bash
npm run android
```

```text
  favorite.tsx    сохранённые стихи

  rugaciuni.tsx   молитвенный дневник

  contacte.tsx    контакты и эфир
  setari.tsx      оформление, шрифт, уведомления, язык
  thank-you.tsx   экран благодарности
  istoria.tsx     история церкви и YouTube-видео
lib/              Библия, стих дня, планы, тема, хранилище, уведомления
content/church.json   расписание/объявления/контакты (обновляются с GitHub)
data/daily-verses.json  стихи дня (RO + RU)
assets/bible/     текст Библии (ro.bible, ru.bible)
tools/build-bible.py    генератор текста Библии и стихов дня
assets/
  images/         иконка, фон церкви, QR asset
components/
  LanguageToggle.tsx
config/
  links.ts        MIA payment link и суммы пожертвования
i18n/
  translations.ts переводы RU/RO
docs/
  screenshots/    доказательство работы приложения
```

## Текст Библии

`assets/bible/*.bible` и `data/daily-verses.json` генерируются скриптом `tools/build-bible.py` из getbible.net (Cornilescu 1924, Синодальный перевод 1876 — общественное достояние). Скрипт исправляет склеенные слова в румынском тексте и перенос заголовков Псалмов в русском.
